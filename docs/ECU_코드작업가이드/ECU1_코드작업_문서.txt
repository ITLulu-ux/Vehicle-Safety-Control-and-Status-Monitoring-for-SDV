ECU1(Environment ECU) 코드 작업 문서

1. 프로젝트 개요

-   역할 : 환경 데이터 수집 ECU
-   센서 : DHT11(온도/습도), BH1750(조도)
-   기능
    -   환경 센서 데이터 수집
    -   CAN을 통한 환경 데이터 송신
    -   Heartbeat 송신
    -   ECU4 제어 명령 수신
-   CAN ID
    -   환경 데이터 : 0x300
    -   Heartbeat : 0x701
-   FreeRTOS Task
    -   SensorTask
    -   CanTxTask
    -   CanRxTask
    -   HeartbeatTask

2. 개발 환경

-   MCU : STM32F446RE
-   IDE : STM32CubeIDE
-   RTOS : FreeRTOS (CMSIS V1)
-   통신 : CAN, I2C
-   Timer : TIM2
-   Git Branch : feature/ecu1

6. 중요 코드 설명

Queue

SensorTask → xQueueOverwrite() → Queue → CanTxTask → xQueueReceive() →
CAN 송신

Binary Semaphore

CAN RX Interrupt → xSemaphoreGiveFromISR() → CanRxTask →
xSemaphoreTake() → CAN_ProcessRxMessage()

Heartbeat

-   1초 주기 송신
-   CAN ID : 0x701

9. 데이터 흐름

DHT11 / BH1750 → SensorTask → SensorData → Queue → CanTxTask → CAN →
ECU3, ECU4

10. CAN Frame 정의

환경 데이터 (CAN ID : 0x300) - Byte0~1 : Temperature - Byte2~3 :
Humidity - Byte4~5 : Lux - Byte6 : Reserved - Byte7 : Reserved

Heartbeat (CAN ID : 0x701) - Byte0 : ECU Status - Byte1~7 : Reserved
